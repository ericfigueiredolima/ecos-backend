# ECOS - Back-end

Repositório oficial da API e regras de negócio do sistema **ECOS**, desenvolvido em **Node.js** com integração ao **Supabase** como parte do projeto acadêmico (PEX).

## 🚀 Sobre o Projeto
O back-end fornece os serviços e endpoints necessários para a autenticação, gerenciamento de funcionários (CRUD), controle de projetos e prazos, além de gerenciar as relações institucionais do ecossistema ECOS.

## 🛠️ Tecnologias Utilizadas
* **Node.js**
* **Express** (ou framework escolhido)
* **Supabase** (Banco de dados relacional e autenticação)
* **JavaScript / TypeScript**

## 📋 Pré-requisitos
Certifique-se de ter instalado em sua máquina:
* [Node.js](https://nodejs.org/) (versão LTS recomendada)
* Gerenciador de pacotes `npm` ou `yarn`
